Privacy Policy

Effective: September 3, 2026

Finish First Version 1.0 is designed as a local-first personal project focus application.

Data stored by the app

Projects, milestones, ideas, sprint tasks, Daily Focus tasks, Done Log entries, and planner settings are stored locally on your device using a local SQLite database.

No Finish First account or cloud sync in Version 1.0

Version 1.0 does not require a Finish First account and does not upload your planner database to a Finish First cloud synchronization service.

Backups

If you choose Export backup, the app creates a portable JSON representation of your planner data and presents the system sharing or file workflow. You decide where that exported file is stored or sent. If you later import a backup, its contents replace the current local planner state on that device.

Feedback sharing

If you use Send beta feedback, Finish First opens the operating system share sheet with a feedback template. Any service you select to send that feedback (for example, an email provider) processes information according to that service's own privacy practices.

Website

This static support website does not itself provide Finish First accounts, planner synchronization, or payment processing. Your hosting provider may process ordinary web-server information such as IP addresses and request logs according to its own policies.

Changes

If a future Finish First version adds accounts, cloud synchronization, analytics, subscriptions, or other network services, this policy should be updated before those features are released.
