Support

Start with the Help guide for an explanation of each Version 1.0 screen.

Send feedback from the app

Open Settings → Send beta feedback. Finish First opens the system share sheet with a feedback template. Choose Mail or another sharing destination you use.

Please include what you were doing, what you expected, what happened instead, and your device/OS. Do not include passwords or sensitive personal information.

Open the Help guide

Before importing a backup

Import replaces the current local Finish First data on that device. Export a backup first if you want to keep the current state.

Cloud sync

Version 1.0 does not offer cloud synchronization or an online account. A problem that only exists because data did not appear on another device is therefore not a sync failure—the feature is not present in this version.
