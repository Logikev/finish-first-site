Finish First Support

Private Beta • Mac + iPad

If you encounter a problem, have a suggestion, or want to provide feedback about Finish First, we'd like to hear from you.

Before contacting support

Try these steps first:

  1. Quit Finish First completely and reopen it.
  2. Confirm you're using the latest beta version.
  3. Export a backup before troubleshooting data issues.
  4. Note what you were doing immediately before the problem occurred.

When reporting a problem

Please include as much of the following information as possible:

  • Device type — Mac or iPad
  • macOS or iPadOS version
  • Finish First beta version
  • What you were trying to do
  • What you expected to happen
  • What actually happened
  • Whether the problem can be repeated
  • A screenshot if it helps explain the issue

What we'd like beta testers to evaluate

  • The one-active-project approach
  • Project Queue
  • Active Project
  • Milestones
  • Idea Parking Lot
  • Weekly Sprint
  • Daily Focus
  • Done Log
  • Backup and Restore
  • Mac and iPad navigation and layout

One question matters most

Did Finish First actually help you stay focused on one meaningful project?

Backup before major changes

Finish First Beta stores its working data locally. Before installing a substantially different build or testing data-related changes, use:

Settings → Backup & Restore → Export Backup

Current beta limitations

The current beta does not include:

  • Cloud synchronization
  • User accounts
  • Team collaboration
  • Web access
  • AI features
  • Automatic Mac ↔ iPad synchronization
