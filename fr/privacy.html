Politique de confidentialité

En vigueur : 3 septembre 2026

Finish First Version 1.0 est conçu comme une application locale de concentration sur les projets personnels.

Données stockées par l'application

Les projets, jalons, idées, tâches de sprint, tâches des Priorités du jour, entrées du Journal des réalisations et réglages du planificateur sont stockés localement sur votre appareil dans une base de données SQLite locale.

Aucun compte Finish First ni synchronisation infonuagique dans la version 1.0

La version 1.0 ne requiert pas de compte Finish First et ne téléverse pas votre base de données de planification vers un service infonuagique de synchronisation Finish First.

Sauvegardes

Si vous choisissez Exporter la sauvegarde, l'application crée une représentation JSON portable de vos données et affiche le mécanisme de partage ou de fichier du système. Vous choisissez où ce fichier est conservé ou envoyé. Si vous importez ensuite une sauvegarde, son contenu remplace l'état local actuel du planificateur sur cet appareil.

Partage de commentaires

Si vous utilisez Envoyer des commentaires bêta, Finish First ouvre la feuille de partage du système avec un modèle de commentaire. Tout service que vous sélectionnez pour envoyer ce commentaire (par exemple un fournisseur de courriel) traite l'information selon ses propres pratiques de confidentialité.

Site Web

Ce site statique de soutien ne fournit pas lui-même de comptes Finish First, de synchronisation de planificateur ni de traitement de paiements. Votre hébergeur peut traiter les renseignements ordinaires des serveurs Web, comme les adresses IP et les journaux de requêtes, selon ses propres politiques.

Modifications

Si une future version de Finish First ajoute des comptes, une synchronisation infonuagique, des analyses, des abonnements ou d'autres services réseau, cette politique devra être mise à jour avant la publication de ces fonctions.
