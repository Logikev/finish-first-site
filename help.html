Help & How to Use Finish First

A practical guide to the functions that exist in Version 1.0.

Start here: Keep one Active Project at a time. Capture other ideas without abandoning the work already in motion. Version 1.0 is local-first and does not provide cloud synchronization.

1. Dashboard

Use the Dashboard to see the current Active Project, milestone progress, parked ideas, and the next action. It is a summary; edit work from the project, sprint, and daily screens.

2. Idea Log

Capture distracting ideas here instead of switching projects immediately. You can edit or delete an idea, and the app includes a workflow for moving a captured idea into the Project Queue.

3. Project Queue

The Project Queue holds projects you may work on. Review priority, impact, effort, and focus score. Version 1.0 also allows you to create a project directly in the queue. Choose Make Active when you are ready to commit.

4. Active Project

Keep one project Active. Define what finished means, maintain a tiny next action, and use milestones to make progress visible. Activating another project changes which project is treated as active.

5. Weekly Sprint

Choose a small set of tasks for the week and mark them done as you complete them. The sprint is a planning view; it does not automatically create calendar events.

6. Daily Focus

Choose no more than three must-do tasks. The distraction rule and start/shutdown rituals are prompts, not automated actions.

7. Done Log

Record finished work so you have a visible history of completion. Entries are stored locally with the rest of your Finish First data.

8. Settings, backup & restore

Export creates a portable JSON backup. Import replaces the current local data on this device, so export first if you want to preserve the current state. Reset sample data deliberately replaces planner data.

About the screenshots: They show the current English interface. Choose Français in Settings to display the localized navigation and Help/Settings labels in French.
